# rivium_auth_example

Example app for the Rivium Auth Flutter SDK: anonymous sign-in, e-mail sign-up and sign-in, sign-out and account
deletion.

1. Turn on Rivium Auth and the anonymous and e-mail methods for your project in the Rivium Console.
2. Run the app and paste your public project key (`rv_live_...`) into the API key field, or replace
   `rv_live_YOUR_PUBLIC_KEY` in `lib/main.dart`.

```bash
flutter pub get
flutter run
```
